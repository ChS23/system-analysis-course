## Как сдавать

Каждому платформа заводит репозиторий на GitHub — туда и кладутся работы.
Устанавливать ничего не нужно: всё делается в браузере.

1. Войдите на платформу через GitHub и примите приглашение в
   репозиторий — ссылка на него на странице работы.
2. Для каждой работы — своя ветка: на странице репозитория нажмите на
   `main` → впишите имя (`lab1`) → «Create branch».
3. Добавьте файлы: «Add file» → «Upload files» (картинки, `.docx`,
   `.xlsx`, `.bpmn`, `.drawio`) или «Create new file» для markdown.
   Записку можно писать в markdown или в Word — как удобнее.
4. Откройте pull request из ветки в `main`: GitHub сам предложит
   кнопку «Compare & pull request».
5. На платформе на странице работы выберите этот PR и нажмите «Сдать».
   Агент проверит форму, разговор о смысле — на приёмке.

Доработка после замечаний — в тот же PR: дата первой сдачи не меняется.

## Что ещё в работе

Критерии приёмки по всем восьми работам — в `practicum/course.json`:
черновик, по которому курс запущен на платформе. Вопросы на приёмку в
нём написаны по текстам работ; окончательные пишет тот, кто читает
лекции: только он знает, на чём студент проваливается, если делал работу
не сам.

## Как устроена работа

Решения и открытые вопросы — в `.plan/`. Папка скрытая нарочно: она для
того, кто курс делает, а не для того, кто по нему учится. Работы лежат папками `lab1_…`, `lab2_…` — так их читает платформа: она
берёт номер из имени папки, название и цель — из `README.md`.
