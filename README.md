## Практикум

`lab1_…` — `lab8_…` — восемь лабораторных. Это не восемь разных заданий,
а один проект, разрезанный на восемь шагов: студент выбирает реальную
систему, которую видит каждый день, и весь семестр разбирает её тем
инструментом, который только что дала лекция.

Замысел практикума и то, почему он устроен так, — в
[`practicum/`](practicum/README.md). Там же образец критериев в
формате, который читает платформа.

## Чего ещё нет

Критериев приёмки по семи работам из восьми и вопросов, которые задаёт
проверяющий. Вопросы в конце каждой работы — черновик; окончательные
пишет тот, кто читает лекции: только он знает, на чём студент
проваливается, если делал работу не сам.

## Как устроена работа

Решения и открытые вопросы — в `.plan/`. Папка скрытая нарочно: она для
того, кто курс делает, а не для того, кто по нему учится. Работы лежат папками `lab1_…`, `lab2_…` — так их читает платформа: она
берёт номер из имени папки, название и цель — из `README.md`.
